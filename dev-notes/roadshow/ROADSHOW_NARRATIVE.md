## 标题：退一步，够用了

我们一开始也在「自由狂奔」——多槽、侧车、目录插件，能换的全都拆开，像**外核态**一样：边界清晰、什么都能插。

但边界越多，**通信代价**就越实在：trait 分发、JSON-RPC、子进程握手，都会落在每一轮对话上。

后来我们问自己：**为什么不后退一步？一步就够了。**

不是放弃开放，而是在发版时允许同一套契约 **聚合成宏核态（Monolith）**——该焊的焊死，热路径回到进程内直调。开放留在创作与集成；极限性能留给玩偶、无头内核和要压包体的场景。

**金句**：开放是默认档，极限是退一步。  
**防误解**：外核态我们不砍——那是开放实验场的底盘；宏核态是**交付档**，不是路线倒退。

## 四大支柱（设计分量）

| 支柱 | 一句话 |
|------|--------|
| **槽位契约（多槽）** | 记忆/情绪/LLM… 可替换、可混搭、单槽失败可回退 |
| **蓝图 v2** | `slot_registry` 声明谁用谁；同一 type 可多实例合并 |
| **单核双态** | 外核态（PluginHost）↔ 宏核态（焊接），构建时选档位 |
| **双核（可选）** | Stable / Experimental 分区，实验失败快照回滚 |
