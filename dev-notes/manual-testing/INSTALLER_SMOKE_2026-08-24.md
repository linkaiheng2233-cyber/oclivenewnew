## 已修复并验收

### P1 · ChatPro 图标覆盖全部 Windows 与彩蛋界面

原始问题：

1. Windows 快捷方式没有显示本轮确认的 ChatPro 图标。
2. 任务栏 / 窗口菜单区域没有显示本轮确认的 ChatPro 图标。
3. Win98 彩蛋界面的合成标题栏没有显示本轮确认的 ChatPro 图标。

修复结果：上述三个入口统一使用已写入 Tauri 图标集的 ChatPro 图标；小尺寸下仍可辨识，不再显示空白、Tauri 默认图标或旧版素材。

排查范围：

- NSIS / MSI 快捷方式图标来源与 Windows 图标缓存；
- Tauri Windows 可执行文件和窗口图标；
- `Win98TitleBar` 使用的前端静态图标资源；
- 安装、首次启动、固定任务栏及覆盖安装后的人工回归。

验收证据：

- 桌面与开始菜单快捷方式均显式指向安装目录中的 `icons\icon.ico`；
- Tauri 主窗口在 Windows 启动时显式加载内嵌 PNG 图标；
- Win98 彩蛋标题栏改用同一套 32×32 图标；
- 用户完成最终安装、启动与界面检查后确认“都没问题”。

验收状态：`PASS`。

### P1 · 安装包不得携带开发者聊天历史

原始问题：早期测试安装后看到了既有聊天记录，需要排除“测试数据被打包”的可能。

修复与核验：

- 发布角色暂存改为仅复制 Git 跟踪的正式角色包；
- 安装包静态扫描未发现 `app.db`、聊天记录、本地状态或调试角色；
- 干净数据目录首次启动仅得到 14 个正式角色和 7 个正式插件；
- 既有聊天来自本机 `%LOCALAPPDATA%\OCLive`，不是安装包内容；测试后已恢复用户原数据。

验收状态：`PASS`。
