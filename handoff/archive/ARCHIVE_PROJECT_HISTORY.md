# 历史资料查阅说明

本目录仅保留历史资料的查阅入口。旧阶段报告、审查流水和已完成执行计划已移至维护者个人文档，不随当前源码分发；不作为当前架构、状态、路径或测试数字的依据。

| 需要查什么 | 当前入口 |
|---|---|
| 版本变化 | [CHANGELOG](../../CHANGELOG.md) |
| 模块职责和接入 | [MODULE_MAP](../MODULE_MAP_AND_HANDOFF.md) |
| 关键代码位置 | [BUS_FACTOR_NOTES](../BUS_FACTOR_NOTES.md) |
| 当前债务和冻结 | [TECHNICAL_DEBT_INVENTORY](../TECHNICAL_DEBT_INVENTORY.md) |

历史来源保留原文件名及受检 SHA。已有证据引用指向固定 Git 版本；也可用 `git log -- <原相对路径>` 和 `git show <当时SHA>:<原相对路径>` 取回原文。当前树的整理没有改写旧提交、旧结论或历史 tag。
