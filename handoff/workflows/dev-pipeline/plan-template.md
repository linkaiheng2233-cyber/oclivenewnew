# 可续跑工程计划模板

**SSOT 范围 / 最后更新**：通用任务计划字段与续跑坐标；2026-09-28。

已有项目计划能表达以下内容时直接复用。此模板是可替换占位，不是开工许可，也不要求无意义的新文档。

```markdown
# <任务>

- 目标 / 可观察的通过条件：
- base SHA / 工作树及已有改动：
- 尺寸及风险原因：
- 事实 owner / 适用项目规则：
- 范围 / 非目标 / 已有授权：
- 影响链（生产者→契约→适配/权限→消费者→状态/回退→测试）：
- 待决问题；不依赖答案可先做的工作：

| 切片 | 文件或能力范围 | 验收命令与适用原因 | 产出 | 失败止点与回退 |
|------|----------------|--------------------|------|----------------|
| 1 | | | | |

- CI 节奏：切片窄测；冻结里程碑；全量/远端要求及权限。
- 状态出口：Implemented / Locally verified / Done-eligible；不满足时保留的父项状态。
- 续跑：最后动作 / head SHA / 下一条精确动作 / retry_safe。
```
