# Voice reference audio (role pack SSOT)

Place 16 kHz mono WAV files for CosyVoice2 zero-shot / emotion mapping:

- `ref_neutral.wav` — default persona
- `ref_happy.wav`, `ref_sad.wav`, `ref_shy.wav` — optional `ref_map` in `voice_profile.json`

Authors bundle these with the role pack. OCLive does not ship subscribed cloud voices.

Minimum spec: 3–10 seconds clear speech, single speaker, low background noise.
