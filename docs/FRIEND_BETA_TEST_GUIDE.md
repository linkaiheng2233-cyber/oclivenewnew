# OCLive 朋友内测指南（Windows x64）

感谢帮忙试用。本包内含 **3 个独立安装程序**（均为 NSIS 向导），可按需安装；**主应用**是日常对话用的桌面端。

组织者若在桌面准备了文件夹 **`OCLIVE_BETA_FOR_FRIENDS`**，其中文件建议为：

| 文件名 | 用途 |
|--------|------|
| **`01_oclivenewnew_0.2.0_x64-setup.exe`** | **主应用**：角色对话（版本以文件名中的 `0.2.0` 为准） |
| **`02_oclive-pack-editor_0.2.0_x64-setup.exe`** | **角色包编写器**：编辑/导出角色包 |
| **`03_oclive-launcher_0.1.1_x64-setup.exe`** | **启动器**：内置/携带 Ollama 安装资源，体积较大（约数百 MB），按需安装 |

若你收到的文件名略有不同（例如未加 `01_` 前缀、启动器原名含中文「启动器」），以 **`*_x64-setup.exe`** 为准即可。

---

## 一、安装包说明（发给你的文件）

| 类型 | 典型文件名 | 用途 |
|------|------------|------|
| **主应用** | `oclivenewnew_*_x64-setup.exe` | 角色对话主程序（Tauri 桌面客户端） |
| **角色包编写器** | `oclive-pack-editor_*_x64-setup.exe` | 编辑/打包角色包（`.ocpak` 等），给创作者用 |
| **启动器** | `oclive-launcher_*_x64-setup.exe` 或 `oclive 启动器_*_x64-setup.exe` | 辅助准备本机 Ollama 等环境（包体较大属正常） |

安装时均可 **自选安装目录**，并按向导勾选 **桌面 / 开始菜单快捷方式**。

> **安全提示**：未做代码签名的安装包，Windows 可能出现「已保护你的电脑」——选「更多信息」→「仍要运行」即可（仅当你信任分发来源时操作）。

---

## 二、测试环境建议

- **系统**：Windows 10 / 11，**64 位（x64）**。
- **WebView2**：一般系统已自带；若主程序窗口无法打开，再安装 [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。
- **本机对话模型（Ollama）**：若使用本地模型，需本机安装 [Ollama](https://ollama.com/) 并拉取对应模型；也可用 **启动器** 按产品说明协助准备环境（视版本而定）。
- **网络**：若使用云端 API / 远程插件，需网络畅通。

## 三、推荐测试顺序（可按兴趣跳过）

### 1. 主应用（必测）

1. 安装并启动 **oclivenewnew**。
2. **加载角色**：使用自带示例角色或导入角色包（若有）。
3. **发几条消息**：观察回复是否正常、是否卡顿或闪退。
4. **切换场景 / 设置**：随意点开设置、插件相关入口，看是否报错。
5. **卸载（可选）**：系统「应用和功能」中卸载，确认无残留需求可忽略。

**请反馈**：系统版本、能否稳定对话、崩溃步骤（越具体越好）、截图或录屏。

### 2. 角色包编写器（可选）

1. 安装 **oclive-pack-editor**。
2. 新建或打开一个角色包工程，保存/导出。
3. 将导出包在主应用中导入（若流程支持），看是否能正常加载。

**请反馈**：能否完成「编辑 → 导出 → 主应用可用」闭环。

### 3. 启动器（可选）

1. 安装 **oclive 启动器**。
2. 按界面指引检查/安装 Ollama 等（以当前版本界面为准）。
3. 再打开主应用，验证能否连上本机模型。

**请反馈**：启动器哪一步不清晰、是否与主应用衔接顺畅。

## 五、分发方备注（给组织者）

- 三仓版本号可能不一致（主应用 `package.json` / 各仓 `tauri.conf.json`），发包前建议核对。
- 仅发 **NSIS `*_x64-setup.exe`** 即可，无需再发裸 `exe`。
- 主应用仓库根目录 `README.md` 中有 `check:release`、打包命令等开发说明；内测分发以本指南 + 三个安装包为最小集合。
