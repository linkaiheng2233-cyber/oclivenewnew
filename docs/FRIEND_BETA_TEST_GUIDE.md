# OCLive 内测说明 · 注意事项 · 常见问题（Windows x64）

感谢参与试用。本文配合压缩包内的安装程序使用；**版本号以你收到的文件名为准**。

---

## 压缩包里通常有什么

组织者会提供下列文件（名称可能带 `01_` 等前缀，或略有不同）：

| 建议顺序 | 内容 | 说明 |
|----------|------|------|
| ① | **Ollama 官方安装包**（`.exe`，来自 [ollama.com](https://ollama.com/)） | **本地跑模型时建议先装**。与 OCLive 独立，需自行接受 Ollama 的许可与更新策略。 |
| ② | **主应用** `oclivenewnew_*_x64-setup.exe` | 日常对话客户端（NSIS 安装向导）。 |
| ③ | **角色包编写器** `oclive-pack-editor_*_x64-setup.exe` | 编辑 / 导出角色包（按需安装）。 |
| ④ | **启动器** `oclive-launcher_*_x64-setup.exe` 或含「启动器」字样的 `*_x64-setup.exe` | **可选**：辅助检测或引导本机环境；若已用官方 Ollama 安装包装好，可不装启动器。 |

**识别方式**：OCLive 三个程序均为 **NSIS**，文件名一般含 **`_x64-setup.exe`**；Ollama 安装包为 **Ollama 官网提供的 Windows 安装程序**，文件名以实际下载为准（例如 `OllamaSetup.exe`）。

## 一、测试说明（推荐你怎么装、怎么测）

### 1. 安装顺序（本地模型场景）

1. **（若用本地模型）先安装 Ollama**  
   运行组织者提供的 Ollama 安装包，按向导完成。装好后可在开始菜单找到 Ollama，并确保其能正常在后台运行。  
2. **在 Ollama 中拉取至少一个模型**（若组织者未说明模型名，可先试常见开源名如 `qwen2.5:7b`，以你方文档为准）。  
   - 可在系统终端执行：`ollama pull <模型名>`  
3. **安装主应用** `oclivenewnew_*_x64-setup.exe`  
   安装时可自选目录，建议勾选「开始菜单 / 桌面快捷方式」便于找到。  
4. **（可选）安装角色包编写器**  
   仅在你需要编辑、导出角色包时安装。  
5. **（可选）安装启动器**  
   若组织者希望你验证「一站式引导」，再安装；若你已按第 1 步装好 Ollama，可跳过。

### 2. 基础功能测试（建议人人做）

1. 打开 **主应用**，任选内置或示例角色，**连续发送 3～5 条消息**，看是否有回复、是否卡顿或闪退。  
2. 打开 **设置** 或与模型相关的入口，确认无整页报错。  
3. **切换场景**（若界面有）或简单切换页面，再发一条消息，看是否正常。  
4. （可选）**导入角色包**或切换角色，再试一轮对话。

### 3. 编写器测试（可选）

1. 打开 **角色包编写器**，新建或打开工程，保存或导出为包。  
2. 在主应用中 **导入** 该包，看角色是否能加载、对话是否正常。

### 4. 测完可做的事

- 把现象记下来（见文末 **反馈模板**）。  
- 若无需保留，可在 Windows **设置 → 应用 → 已安装的应用** 中卸载各程序；**Ollama** 也可单独卸载。

## 二、注意事项（请先看）

### 系统与环境

- **系统**：Windows 10 / 11，**64 位（x64）**；ARM 设备未在本次内测范围内。  
- **磁盘**：主应用 + 编写器 + 启动器约占用有限；**模型与 Ollama 数据可能占用数 GB～十余 GB**，请预留空间。  
- **网络**：首次拉取模型、使用云端 API 或远程插件时需要网络；纯本地推理在模型已下载后可在离线试跑（视配置而定）。  
- **杀毒 / 防火墙**：未签名的安装包可能被拦截或提示风险；请仅在 **信任组织者来源** 的前提下选择「仍要运行」或加入白名单。

### 安装与运行

- **管理员权限**：一般双击安装即可；若写入受保护目录失败，可尝试「以管理员身份运行」安装包。  
- **WebView2**：多数系统已自带；若主程序 **窗口白屏或无法启动**，再安装 [Microsoft Edge WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。  
- **Ollama 与 OCLive 的关系**：Ollama 是独立软件；主应用通过本机网络连接 Ollama 服务。**先装 Ollama 并保证其运行**，再在主应用里选对应本机模型（具体入口以界面为准）。  
- **多个安装包不要混版本**：以组织者提供的成套文件为准，不要随意替换其中某一个为其他版本（除非组织者说明）。

### 安全与隐私

- 内测包 **可能未做代码签名**，Windows SmartScreen 可能出现「已保护你的电脑」→ 选 **更多信息** → **仍要运行**（仅当你信任来源时）。  
- 勿向内测包中提交真实敏感个人信息；测试对话内容请自行斟酌。

## 三、常见问题（FAQ）

**Q1：安装时提示「已保护你的电脑」怎么办？**  
A：多为未签名导致。在确认来源可信后，点 **更多信息** → **仍要运行**。若公司策略禁止，需联系组织者或 IT。

**Q2：主程序打不开、闪退或白屏？**  
A：依次检查：① 是否 **x64 Windows**；② 安装 **WebView2 运行时**；③ 显卡驱动是否过旧；④ 把报错截图或事件发给组织者。

**Q3：对话一直没回复或提示连不上模型？**  
A：① 若用 **本地 Ollama**：确认 Ollama 已安装且托盘/服务在运行；② 确认已 **`ollama pull`** 对应模型；③ 主应用内模型名是否与 Ollama 中一致；④ 防火墙是否拦截本机端口（默认以 Ollama 文档为准）。

**Q4：我已经装了组织者给的 Ollama 安装包，还要装「启动器」吗？**  
A：**不必须。** 启动器用于辅助环境准备；若 Ollama 已能正常使用，可只测主应用 + 编写器。

**Q5：启动器很大、下载很慢？**  
A：启动器可能内置或携带较大资源，属正常。若你只关心对话，可优先 **Ollama 官方包 + 主应用**。

**Q6：三个 NSIS 都要装吗？**  
A：**只有主应用是核心。** 编写器、启动器按你是否要测「做包」「引导环境」决定。

**Q7：卸载后数据还在吗？**  
A：Windows 卸载通常移除程序文件；**用户数据、模型缓存** 可能在各自数据目录（如 Ollama 模型目录、应用数据目录）。需要彻底清理时再问组织者或查各产品说明。

**Q8：macOS / Linux 能测吗？**  
A：本次内测包若为 **Windows x64** 安装包，则仅适用于 Windows；其他系统需组织者另提供构建。
