# oclive 用户操作手册

面向 **只使用应用、不写角色包也不开发插件** 的用户。技术细节与错误码速查见 [ERROR_CODES.md](ERROR_CODES.md)；安装与开发构建见根目录 [README.md](../../README.md)。

---

## 1. 安装与首次启动

### 1.1 系统要求

| 项目 | 说明 |
|------|------|
| **操作系统** | 以当前发行说明为准；**Windows** 与 **Linux** 为常见支持组合（详见仓库 CI 与发行页）。 |
| **硬件** | 本地运行大语言模型对 **内存与磁盘** 有要求；若仅使用云端侧车，要求以侧车文档为准。 |
| **Ollama** | 使用 **本地 Ollama** 对话时，需本机已安装 [Ollama](https://ollama.com/)，并已 **`ollama pull`** 至少一个聊天模型。具体模型名可在角色包或设置中配置。 |

### 1.2 安装应用

- 从项目或发行渠道获取 **离线安装包**（当前以离线包分发为主；见根目录 README「可观测性与发布」）。  
- 按操作系统习惯完成安装；**首次启动**若出现防火墙或安全软件提示，请按策略放行（否则本地服务可能无法连接）。

### 1.3 首次启动可以做什么

1. 若界面为中文，想改为英文：见下文 **「设置 → 常规 → 语言」**。  
2. 确认 **角色包** 已就绪：可使用应用内 **导入**，或事先用 [oclive-launcher](https://github.com/linkaiheng2233-cyber/oclive-launcher) 将 zip 安装到 `roles` 根（见 [CREATOR_WORKFLOW.md](CREATOR_WORKFLOW.md) 中普通用户相关小节）。  
3. 打开 **设置 → 常规 → 环境自检**，确认本机 **Ollama 可达**、角色目录可读、应用数据可写。

### 1.4 如果 Ollama 不可达

1. 确认 Ollama 服务已启动，且浏览器或命令行能访问其默认地址（见环境自检结果中的 URL）。  
2. 在终端执行 **`ollama pull <模型名>`** 拉取模型。  
3. 若仍失败：请查看 [ERROR_CODES.md](ERROR_CODES.md) **§1.5** 首装与模型相关说明，并在反馈 issue 时附上 **环境自检摘要**（勿粘贴 API 密钥）。

## 2. 角色包管理

### 2.1 如何导入角色包

1. 在应用内找到 **角色包 / 导入** 相关入口（通常为 **`.ocpak` / `.zip` 压缩包** 或已解压文件夹，以界面提示为准）。  
2. 若导入包与已有角色 **ID 冲突**，界面会提示是否 **覆盖**；请确认后再操作。  
3. 导入过程中若耗时较长，请等待 **进度提示** 结束，勿强制关闭窗口。

### 2.2 如何切换角色

- 在 **角色列表或顶栏** 中选择其他角色（具体控件随主题与布局略有不同）。  
- 切换后首条对话前可能会进行 **启动健康检查**（槽位、插件、数据库等）；若失败请根据提示或 [ERROR_CODES.md](ERROR_CODES.md) 排查。

### 2.3 角色包市场在哪

- **应用内**：若已接入 **社区插件/角色索引**，通常在工作台或设置相关入口中提供「刷新索引 / 浏览」类功能；弱网时可能使用 **本地缓存** 并显示提示条。  
- **索引格式说明**（给好奇用户）：见 [../role-pack/ROLE_PACK_INDEX.md](../role-pack/ROLE_PACK_INDEX.md)。  
- **用启动器从 zip 安装**：见 [oclive-launcher README](https://github.com/linkaiheng2233-cyber/oclive-launcher/blob/main/README.md)。

## 3. 日常对话

### 3.1 聊天界面简介

- **主区域**：消息列表与输入框。  
- **侧栏**：常含角色信息、场景、好感等（随角色包 `ui.json` 与模式变化）。  
- **「异地 / 共景」等模式**：若角色包开启相关能力，界面可能出现额外条或提示（详见 [ERROR_CODES.md](ERROR_CODES.md) 与共景相关 FAQ）。

### 3.2 快捷键（常用）

| 快捷键 | 作用 |
|--------|------|
| **Ctrl+Shift+S** | 打开 **设置** |
| **Ctrl+Shift+F** | 打开 **已安装插件** 列表（开关 / 卸载 / 安装 zip / 市场）；含 UI 的插件启用时会弹出 **位置选择** |
| **Ctrl+Shift+D** | 打开/关闭 **调试面板**（开发者向） |
| **长按 Ctrl**（约 1 秒） | 可打开 **快捷键说明** 浮层（若版本已启用该交互） |

完整列表以应用内 **快捷键说明** 为准。

### 3.3 如何查看对话历史

- 在消息列表中 **向上滚动**；若存在 **「更早消息」折叠区**，可按提示 **展开** 以加载更早块（见界面文案）。  
- 历史条数与折叠策略由产品实现与角色场景共同决定。

### 3.4 用户身份（v0.3）

若角色包提供了 **`user_identities/`** 目录（示例：`mumu`），可在 **调试面板**（**Ctrl+Shift+D**）内的 **运行时** 区域通过 **「用户身份」** 下拉切换「用户是谁」的 Prompt 模板（如「同班同学」）。切换后 **下一条消息** 起生效；与 **关系** 下拉（好感阶段）相互独立。

- **跟随包默认**：使用 catalog 中 `default_identity_id` 对应模板。  
- 无 `user_identities/` 的角色包不显示该下拉；仍可使用 **关系** 下拉（legacy `user_relations`）。

### 3.5 回复后处理（创作者向 · 默认关闭）

**回复后处理** 用于在 LLM 生成文本后再做修饰（如截断、去引号）。属于 **高级 / 创作者配置**（角色包 `config.json` → `reply_post_processor`），**默认不启用**；普通用户通常无感。启用后可在调试面板 **运行时** 区域看到只读状态行（后端类型与 profile）。详见 [ROLE_PACK_SPEC §9.7](../role-pack/ROLE_PACK_SPEC.md)。

## 4. 设置指南

### 4.1 常规设置

- **语言**：设置 → 常规 → **界面语言**（如 中文 / English / 跟随系统）。切换后若个别位置仍有非当前语言文案，可能为 **长尾未翻译** 或 **插件自带文案**；可反馈 issue。  
- **遥测（Sentry）**：若构建包含 DSN，可在设置中 **退出崩溃上报**（详见 [ERROR_CODES.md](ERROR_CODES.md) §1.7 与 [A3 结项](../../handoff/A3_CLOSURE_SUMMARY.md)）。  
- **环境自检**：设置 → 常规 → **运行检测**，用于快速确认 Ollama、目录与写权限。

### 4.2 LLM 后端配置

- 默认路径多为 **本机 Ollama**；若角色包或作者建议指定模型，请以 **环境自检** 与角色说明为准。  
- 使用 **远端 HTTP 侧车** 或闭源 API 时，属于 **进阶配置**，见 [SIDECAR_LLM_USER_GUIDE.md](SIDECAR_LLM_USER_GUIDE.md)（用户向侧车指南）。

### 4.3 兜底策略开关

- 设置中可能提供 **「远端失败时回退内置」** 等开关（与 `app_settings` 中键一致，见 [../guides/CONFIGURATION_FILES.md](../guides/CONFIGURATION_FILES.md)）。  
- 若某项呈灰色不可改，可能表示 **环境变量已锁定**，以界面说明为准。

## 5. 常见问题（FAQ）

### 5.1 为什么 AI 回复很慢？

- **本机模型**：首次拉取或冷启动会慢；机器性能与上下文长度影响明显。  
- **远端模型**：受网络与服务商限速影响。  
- 可在 **调试面板**（若开启）查看本回合耗时与是否走了备用回复（见 [ERROR_CODES.md](ERROR_CODES.md)）。

### 5.2 为什么我切到英文后还是看到中文？

- 部分 **插件、角色包自带文案** 未走宿主 i18n。  
- **长尾界面** 仍在翻译收口中，见 [产品清单 §A6](../../handoff/PRODUCT_AND_KERNEL_GAP_CHECKLIST.md)。  
- 若确认是主界面遗漏，欢迎带 **截图与版本号** 提 issue。

### 5.3 如何卸载插件？

- 打开 **插件管理**（**Ctrl+Shift+F**），在列表中 **关闭开关** 或 **卸载**。声明了界面插槽的插件在 **打开开关** 时会提示选择显示位置（如侧栏、聊天工具栏等）。  
- **架构图 / 多槽位蓝图** 不在应用内提供，请用 **`oclive plugin manage`**（见 [OCLIVE_CLI_GUIDE.md](../cli/OCLIVE_CLI_GUIDE.md)）。  
- **目录插件** 删除后可能需 **重启应用** 才能完全释放资源；详见 [../plugin-and-architecture/DIRECTORY_PLUGINS.md](../plugin-and-architecture/DIRECTORY_PLUGINS.md) 用户可见部分。
